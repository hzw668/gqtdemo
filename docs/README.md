## 🎯 核心亮点

### 💡 业务亮点

1. **自动化数据回流** ⭐⭐⭐
   - ECIF、核心系统、薪福宝等多系统数据自动汇聚
   - 针对性展示：仅显示本客户已签约产品的使用数据
   - 数据溯源标签：每条数据标注来源系统 + 更新时间

2. **智能待办分类**
   - 待触达拜访：新开户 T+1 自动注入
   - 预警回访：网银/薪福宝停用、代发下降自动触发
   - 铁三角路演：对公+零售+科技协同
   - 模块深度提升：已签约低使用率客户

3. **功能诉求归集需求池**
   - 客户经理拜访时勾选功能诉求
   - 自动归集至总行需求池
   - 推动产品持续优化

4. **清单全流程可追溯**
   - 总行下发 → 分行接收 → 客户经理跟进
   - 批次管理、进度跟踪、管户调整留痕

### 🔧 技术亮点

1. **JSONB 灵活存储**
   - 产品使用数据、预警原因等动态字段
   - 支持复杂查询与索引

2. **事件驱动架构**
   - Kafka 消息队列解耦业务系统
   - 异步处理数据回流

3. **规则引擎**
   - 预警规则可配置
   - 待办自动归集

4. **数据血缘追溯**
   - 每条回流数据记录来源系统 + 时间戳
   - 便于问题排查

## 🔄 数据回流机制

### 回流数据源

| 数据源 | 回流内容 | 更新频率 |
|--------|----------|----------|
| **ECIF** | 签约产品、企业网银登录、银信通状态、理财余额 | T+1（每日08:30） |
| **核心系统** | 代发笔数、代发金额、账户交易 | 实时/T+1 |
| **薪福宝** | 模块开通情况、登录次数、使用深度 | 实时 |
| **开户系统** | 新开户识别、自动注入清单 | T+1 |
| **流水跑批** | 授信机会识别 | 每日批量 |

### 回流流程

```
业务系统 → 数据中台（ETL/规则引擎） → CRM 数据库 → 移动端展示
  ↓           ↓                        ↓              ↓
ECIF       标准化清洗              自动回写        针对性展示
核心       规则匹配                JSONB存储      数据溯源标签
薪福宝     预警触发                Redis缓存      异常红色标注
```

## ❓ 常见问题

### Q1：为什么有的客户没有产品使用数据？
**A：** 采用「针对性回流」机制，仅展示本客户已签约的产品数据。未签约客户显示空态提示。

### Q2：数据更新频率是多少？
**A：** 
- 薪福宝：实时
- 核心系统（代发）：实时/T+1
- ECIF（网银、理财）：T+1（每日08:30）
- 每条数据都带溯源标签，如 `[核心 · 06-24]`

### Q3：功能诉求如何同步到需求池？
**A：** 客户经理在拜访跟进录入表单中勾选「客户需求（功能诉求）」，填写后保存时自动归集至总行需求池。

### Q4：清单是如何流转的？
**A：** 
```
总行下发 → 分行接收 → 分配至客户经理 → 触达跟进 → 转化/复盘
```
- 园区批量：总行手动下发
- 增量注入：开户系统 T+1 自动注入
- 存量清单：ECIF 定期推送
