### 1.2 技术栈选型建议

**前端：**
- 原生 HTML5 + CSS3 + JavaScript（当前 Demo）
- 或升级为 Vue 3 / React（生产环境推荐）
- UI 组件库：Vant / Ant Design Mobile

**后端：**
- Java：Spring Boot + Spring Cloud（微服务）
- Node.js：Nest.js（BFF 层）
- Python：FastAPI（数据处理/AI 建议）

**数据库：**
- 主库：PostgreSQL 14+（支持 JSONB）
- 缓存：Redis 7.0+
- 搜索：Elasticsearch 8.0+（客户搜索、需求池检索）

**中间件：**
- 消息队列：Kafka / RocketMQ（数据回流）
- 任务调度：XXL-JOB（定时同步）
- 配置中心：Nacos / Apollo

## 📊 二、数据库设计

### 2.1 核心表结构

#### 2.1.1 客户主表（crm_customer）

```sql
CREATE TABLE crm_customer (
    id BIGINT PRIMARY KEY,
    customer_name VARCHAR(200) NOT NULL COMMENT '客户名称',
    unified_social_credit_code VARCHAR(50) UNIQUE COMMENT '统一社会信用代码',
    industry VARCHAR(100) COMMENT '行业',
    customer_source VARCHAR(50) COMMENT '客户来源：新开户/存量/园区批量',
    customer_status VARCHAR(20) NOT NULL DEFAULT 'wait' COMMENT '状态：wait/visit/active/warn/signed/none',
    customer_level VARCHAR(20) COMMENT '客户分层：基础户/有效户/价值户',
    
    -- 归属信息
    branch_id BIGINT COMMENT '归属分行',
    sub_branch_id BIGINT COMMENT '归属中支',
    network_id BIGINT COMMENT '归属网点',
    manager_id BIGINT COMMENT '管户客户经理',
    
    -- 跟进信息
    last_follow_date DATE COMMENT '上次跟进日期',
    next_follow_date DATE COMMENT '计划跟进日期',
    follow_count INT DEFAULT 0 COMMENT '跟进次数',
    
    -- 业务字段
    signed_products JSONB COMMENT '已签约产品：["薪福宝","代发","网银"]',
    roster_batch_ids JSONB COMMENT '所属清单批次ID数组',
    
    -- 预警字段
    is_warning BOOLEAN DEFAULT FALSE COMMENT '是否预警',
    warning_reasons JSONB COMMENT '预警原因数组',
    warning_triggered_at TIMESTAMP COMMENT '预警触发时间',
    
    -- 时间戳
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_manager (manager_id),
    INDEX idx_status (customer_status),
    INDEX idx_branch (branch_id, sub_branch_id),
    INDEX idx_warning (is_warning, warning_triggered_at)
);
```
